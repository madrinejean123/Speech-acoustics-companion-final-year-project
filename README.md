A real-time assistive speech system for people who stammer.

The app listens through a speech block, works out the word the speaker was trying to say, and speaks it aloud in the speaker's own voice, fast enough to fit into a normal conversation.

Standard speech recognition fails these users. It mishears stuttered speech, erases the stutter, or treats a long block as the end of the sentence and cuts the person off. This project is built to do the opposite: stay patient, keep the stutter as useful information, and help only when asked.
